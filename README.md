## Contents

- **8 Parts, 25 Chapters** covering classical GT foundations, IGT axiomatic framework, historical case studies, economic architecture, comparative analysis, and modern applications
- **24 Python simulations** with interactive code viewers and visual outputs
- **Muhammad Equilibrium** — where mutual elevation replaces mutual destruction
